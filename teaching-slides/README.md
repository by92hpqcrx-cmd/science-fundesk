# FunDesk 教學簡報
此資料夾存放首頁「教學快捷入口」可下載的簡報。

## 八大行星英文與神話
請在 GitHub 網頁開啟這個資料夾，選擇 **Add file → Upload files**，上傳以下 PowerPoint 檔案（請保持檔名不變）：

`八大行星英文_神話補充_FunDesk指定淡紫太空背景_21頁.pptx`

提交到 `main` 分支後，首頁新增的 **🪐 八大行星英文與神話** 按鈕就能下載簡報。

> 為避免損壞 PPTX，請以 GitHub 原生的「Upload files」上傳二進位檔，不要將壓縮後的二進位內容貼入文字編輯器。

## 最新 31 頁版本
請從 ChatGPT 下載以下檔案後，使用 GitHub Add file → Upload files 放入本資料夾，提交 main：

`八大行星英文_神話補充_FunDesk太空背景_新增行星構造_分類總結_31頁.pptx`

GitHub Actions「Convert planets PPT to web slides」會優先使用這個 31 頁版本，產生 31 張線上播放圖片及更新 manifest.json。首頁快捷入口不需再修改。
